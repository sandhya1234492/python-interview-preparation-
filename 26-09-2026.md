1. What is Python?
   Answer:
   Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum. It is designed to be easy to read and write, which makes it beginner-friendly. Python is widely used in web development, scripting, automation, data analysis, artificial intelligence, machine learning, and software development.

   - Large standard library
   - Platform-independent
   - Automatic memory management

11. How does Python work internally?
   Answer:
   Python works in a layered process:
   - The source code is written by the developer
   - The Python parser reads the code and converts it into an abstract syntax tree (AST)
   - The compiler converts the AST into bytecode
   - The Python Virtual Machine (PVM) executes the bytecode step by step
   - Built-in libraries and memory management handle runtime tasks

   The most common Python interpreter is CPython, which is written in C.

12. Explain Python architecture.
   Answer:
   Python architecture consists of the following main components:
   - Source code: The Python program written by the developer
   - Parser: Converts the source code into a syntax tree
   - Compiler: Converts syntax tree into bytecode
   - Python Virtual Machine (PVM): Executes bytecode
   - Standard library and modules: Provides built-in functionality
   - Memory manager and garbage collector: Manages memory and removes unused objects

   This architecture makes Python portable, easy to understand, and suitable for many kinds of development.

13. What is indentation in Python, and why was it introduced instead of semicolons or braces used in other programming languages?
   Answer:
   Indentation is the spaces or tabs used at the beginning of a line to define a block of code. In Python, indentation is required to mark blocks such as loops, conditionals, functions, and classes.

   Example:
   if True:
       print("This is inside the block")

   Python uses indentation instead of braces {} or semicolons because it makes code cleaner, consistent, and easier to read. Other languages like C, C++, or Java use braces to define code blocks; Python uses indentation to enforce a readable and standardized structure.

15. What are variables in Python, and how do they differ from other programming languages?
   Answer:
   Variables are named storage locations used to hold data values. In Python, variables are created when a value is assigned.

   Example:
   name = "Alice"
   age = 25
   is_student = True

   Python variables are dynamically typed, meaning you do not need to declare the type explicitly. In languages like Java, C, or C++, you usually must declare the data type before assigning a value. Python is more flexible and easier to write.

16. What are data types in Python, and how do they differ from other backend programming languages?
   Answer:
   Data types define the kind of value a variable stores. Python has built-in data types such as:
   - int: integer numbers like 10
   - float: decimal numbers like 3.14
   - str: text data like "Python"
   - bool: True or False
   - list: ordered and mutable collection
   - tuple: ordered and immutable collection
   - set: unordered collection of unique items
   - dict: key-value pairs
   - None: represents no value

   Python is dynamically typed, so the type is inferred automatically. In backend languages like Java or C#, data types are often statically declared, which means the developer must specify them in advance.

17. What are functions in Python, and how do they differ from other backend programming languages? Explain in detail, including syntax and example.
   Answer:
   A function is a reusable block of code that performs a specific task. Functions are used to organize code, avoid repetition, and improve readability.

   Python function syntax:
   def greet(name):
       return "Hello, " + name

   print(greet("Alice"))

   Output:
   Hello, Alice

   Functions in Python are first-class objects, which means they can be assigned to variables, passed as arguments, and returned from other functions. This makes Python highly flexible. Compared with many backend languages, Python functions are simpler, more expressive, and easier to write. They support default arguments, keyword arguments, and variable-length arguments.

18. What are the types of functions in Python? What are arguments and parameters in Python?
   Answer:
   Types of functions in Python include:
   - Built-in functions: Provided by Python, such as print(), len(), sum()
   - User-defined functions: Created by the programmer
   - Anonymous functions: Lambda functions
   - Recursive functions: Functions that call themselves
   - Nested functions: Functions defined inside another function
   - Higher-order functions: Functions that accept other functions as arguments

   Parameters are variables listed in the function definition.
   Arguments are the actual values passed to the function when it is called.

   Example:
   def add(a, b):
       return a + b

   result = add(5, 3)
   print(result)

   In this example, a and b are parameters, and 5 and 3 are arguments.

   Python supports various kinds of arguments:
   - Positional arguments
   - Keyword arguments
   - Default arguments
   - *args for variable positional arguments
   - **kwargs for variable keyword arguments

   Example:
   def display(name, age=18, *skills, **details):
       print(name, age, skills, details)

   display("John", 25, "Python", "SQL", city="Hyderabad")

   This shows how Python functions can handle flexible and dynamic inputs efficiently.
